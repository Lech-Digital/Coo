# YouTube videos

One folder per video, named `YYYY-MM-DD-slug` (the upload date first, so they sort), each with:

- `video.md` — title, description, chapters, tags and where it came from, ready to paste into YouTube Studio
- `thumbnail.png` — 1280×720 for a 16:9 video, 720×1280 for a Short
- `video.mp4` — the uploaded file (ignored by git; re-render it from the source named in `video.md`)

Copy style follows `../PLAY-LISTING.md`: plain, the words parents search for, no "calm", "3 a.m." or "free" lines.
