# Icon options (2026-10-02)

Drafts from the icon round with the owner. **D2 ("saying coo") was chosen** and is the app icon
(`src/Mobile/Coo.Mobile/Resources/AppIcon/`). The others are kept on purpose, for later updates
(seasonal or alternative icons), at the owner's request.

| File | Direction |
|---|---|
| `a-coo-bird.svg` | A round bird in the four kind colours, two "coo" arcs |
| `b-asleep-on-the-moon.svg` | A sleeping baby in an amber crescent, night colours |
| `c-four-colours.svg` | The four kinds as overlapping circles around Coo's green |
| `d0-first-draft-hairline.svg` | The first speech-bubble draft (its hairline read as an upside-down mouth) |
| `d1-asleep-with-a-curl.svg` | Bubble, sleeping baby with a curl, peach |
| `d2-saying-coo.svg` | **Chosen.** Bubble, awake baby saying "coo", peach |
| `d3-asleep-at-night.svg` | D1 on the night colours |
| `d4-saying-coo-lavender.svg` | D2 on lavender |

All are drawn on a 108 × 108 grid, the adaptive-icon canvas.
