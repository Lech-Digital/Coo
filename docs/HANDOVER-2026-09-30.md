## Ground rules (they apply to every session)

- **A private project.** Coo belongs to Lech Digital and has no connection to Coolblue:
  - no Coolblue design systems, assets or tools (Glean, Atlassian, Datadog, company claude.ai
    artifacts or docs);
  - no project content sent to them;
  - design and documentation stay as local files in this repo.
- **Git identity.** Every commit is authored as `adziusmaster <adzius.lech@gmail.com>`, set in the
  repo-local git config (as in PurePrep and CoreChoice). No `Co-Authored-By` trailer.
- **Self-hosted.** Everything runs on the Hetzner host (`coldstart-prod`, behind the shared Caddy).
  **No Firebase, no FCM**, no hosted identity provider.
- **Spec-driven development.** Code is written only after its spec is agreed.
- **Android first**, iOS maybe later.
- **Seven languages** from day one: en, de, fr, es, it, pl, nl.
- **Product:** "Coo — Baby Log & Sleep". App ID `com.lechdigital.coo`. .NET namespace prefix `Coo`.
